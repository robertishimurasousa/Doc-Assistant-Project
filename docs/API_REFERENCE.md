# Python API reference

Run examples from the repository root in an environment with the dependencies installed. Imports use the `src` namespace; there is no packaged command-line entry point.

## DocumentAssistant

Defined in [src/assistant.py](../src/assistant.py).

```python
DocumentAssistant(document_path=None, session_dir="sessions", llm=None)
```

The constructor creates a retriever, compiled workflow, tools, and session directory. It does not load documents or start a session. Create any parent directories before supplying a nested `session_dir`.

| Method | Return | Behavior |
| --- | --- | --- |
| `load_documents(path=None)` | `int` | Append documents; return the total loaded count. |
| `add_document(content, source, metadata=None)` | `None` | Append an in-memory document. |
| `start_session(session_id=None)` | `str` | Create a fresh transcript with a supplied ID or generated UUID. |
| `process_message(user_input)` | `str` | Run the graph, record messages, and attempt to save. |
| `query(user_query)` | `str` | Alias for `process_message()`. |
| `get_session_history()` | `list[Message]` | Return current messages, or an empty list. |
| `save_session()` | `bool` | Write the current transcript; false on no session or write failure. |
| `load_session(session_id)` | `bool` | Restore a transcript; false if missing or invalid. |
| `list_sessions()` | `list[str]` | Return saved JSON filenames without extensions; no sort guarantee. |
| `clear_session()` | `None` | Detach the current session; do not delete files, documents, or checkpoints. |
| `get_stats()` | `dict` | Return counts and the active session ID. |

Statistics keys are `num_documents`, `num_sessions`, `current_session_id`, and `current_session_messages`.

### Query and resume

```python
from src.assistant import DocumentAssistant
from src.config import get_default_llm

assistant = DocumentAssistant(
    document_path="data/sales_report_q1_2024.txt",
    llm=get_default_llm(),
)
assistant.load_documents()
session_id = assistant.start_session()
print(assistant.query("What does the report say about monthly revenue?"))

# A new instance needs its documents loaded again.
resumed = DocumentAssistant(
    document_path="data/sales_report_q1_2024.txt",
    llm=get_default_llm(),
)
resumed.load_documents()
if resumed.load_session(session_id):
    print(resumed.query("Which month had the highest revenue?"))
```

Reusing `start_session(existing_id)` creates an empty transcript and may later overwrite that ID's JSON file. Use `load_session()` to restore saved messages. Use IDs generated by the application rather than arbitrary paths.

### Add text directly

```python
assistant.add_document(
    content="The project budget is 100000 dollars.",
    source="project-notes",
    metadata={"category": "budget"},
)
```

In-memory documents are not written into the transcript or reloaded automatically.

### Inspect a structured response

After a successful query, inspect the graph checkpoint in the same assistant instance:

```python
from src.schemas import AnswerResponse, CalculationResponse, SummarizationResponse

snapshot = assistant.workflow.get_state({
    "configurable": {"thread_id": assistant.current_session.session_id}
})
response = snapshot.values.get("current_response")

if isinstance(response, AnswerResponse):
    print(response.answer)
elif isinstance(response, CalculationResponse):
    print(response.result, response.explanation)
elif isinstance(response, SummarizationResponse):
    print(response.summary, response.key_points)
```

This uses the workflow implementation interface. `query()` itself does not return these objects. In a new instance, loading a JSON transcript does not restore the checkpoint.

## DocumentRetriever

Defined in [src/retrieval.py](../src/retrieval.py).

```python
from src.retrieval import DocumentRetriever
from src.schemas import Query

retriever = DocumentRetriever("data/sales_report_q1_2024.txt")
retriever.load_documents()
matches = retriever.retrieve(Query(text="monthly revenue"), top_k=3)

for document in matches:
    print(document.source, document.score)
```

| Method | Behavior |
| --- | --- |
| `load_documents(path=None)` | Append files from the supplied or constructor path. |
| `retrieve(query, top_k=5)` | Return positive keyword matches as scored document copies. |
| `add_document(document)` | Append a `Document`. |
| `clear_documents()` | Remove all loaded documents from memory. |
| `get_document_count()` | Return the loaded count. |

`Query.filters` exists in the schema but is not applied. Missing paths load nothing; read failures print an error. Directory extension checks are case-sensitive.

## Models

Defined in [src/schemas.py](../src/schemas.py).

| Model | Principal fields |
| --- | --- |
| `Document` | Required `content`; optional `source`, `score`; `metadata` dictionary. |
| `Query` | Required `text`; optional `filters`. |
| `Message` | Required `role`, `content`; optional string `timestamp`. |
| `Session` | Required `session_id`; `messages` and `metadata`. |
| `UserIntent` | Required `intent_type`, `confidence`, `reasoning`. |
| `AnswerResponse` | Required `question`, `answer`, `confidence`; `sources`, `timestamp`. |
| `CalculationResponse` | Required `expression`, `result`, `explanation`, `confidence`; `units`, `sources`, `timestamp`. |
| `SummarizationResponse` | Required `summary`, `confidence`; `key_points`, `original_length`, `document_ids`, `timestamp`. |

Confidence fields are bounded to 0–1. Intent types and message roles are ordinary strings, not enums. Calculation results are strings. Response timestamps are datetime objects; transcript message timestamps are strings.

## Tools

Defined in [src/tools.py](../src/tools.py).

```python
from src.tools import create_calculator_tool, create_document_reader_tool

calculator = create_calculator_tool()
print(calculator.invoke({"expression": "(50000 + 60000 + 70000) / 3"}))

reader = create_document_reader_tool(retriever)
print(reader.invoke({"query": "monthly revenue"}))
```

The calculator returns strings such as `Result: 60000.0` or error messages. It accepts arithmetic expressions, not variable names, currency symbols, or functions.

The reader returns full text from up to three matches, including source paths, or `No relevant documents found.`. `create_agent_tools(retriever)` returns both tools. The separate `create_default_tools()` registry exposes search, preview, and context helpers; it is not the tool list used by the workflow.
