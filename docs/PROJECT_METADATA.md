## Name

Document Assistant

## GitHub description

Python document assistant using LangGraph, LangChain, and OpenAI-compatible models for Q&A, summarization, and arithmetic over local documents.

## Extended description

Document Assistant is an educational Python application that routes user requests to specialized Q&A, summarization, and calculation nodes. It combines keyword-based document retrieval, LangChain tools, Pydantic response models, and JSON conversation transcripts. Users can explore the workflow through an interactive terminal, a Python API, or a Jupyter notebook, with OpenAI or Vocareum configuration.

## Scope of these claims

The project uses keyword retrieval and local JSON transcripts. It does not implement a vector database, PDF ingestion, a hosted service, or a production deployment. The repository currently has no dedicated documentation website or `LICENSE` file.
